# Qr-code-generator
QR Code Generator with instant preview and download. Type any text/URL and get QR code. Built with HTML, CSS, JavaScript + QR API.
Day 16/100 of #100DaysOfCode. QR Code Generator that converts text/URLs into QR codes instantly. Features live preview and download option. Uses free QR Server API. Built to practice API integration, async image loading, and download functionality. Tech: HTML5, CSS3, Vanilla JavaScript, QR Server API.
